# CodeAlpha_AI-ChatBot-task-3
This project is a Java-based Artificial Intelligence Chatbot developed as part of an internship task. The chatbot can interact with users, understand basic queries, and respond intelligently using rule-based logic.

📌 Features


💬 Interactive chatbot (console-based / GUI-based)


🧠 Basic Natural Language Processing (NLP)


🔁 Rule-based response system


📚 Predefined responses for common questions


⏱️ Handles greetings, date, time, and general queries


🖥️ Optional GUI support using Swing



🛠️ Technologies Used


Java


OOP (Object-Oriented Programming)


Java Collections (ArrayList, HashMap)


Swing (for GUI - optional)



📂 Project Structure
AI-Chatbot/│├── Chatbot.java        # Main chatbot logic├── ResponseHandler.java  # Handles user queries├── GUIChatbot.java     # GUI interface (optional)├── README.md

🚀 How to Run
1️⃣ Compile the program
javac Chatbot.java
2️⃣ Run the chatbot
java Chatbot
